# CPRR - Sistema de Gestión de Aulas

Landing page presentando nuestro Sistema de Gestión de Aulas, una solución digital para organizar aulas, laboratorios y espacios educativos.

## Materia

**Ingeniería en Informática** - ITSE

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla

## Cómo abrir localmente

```bash
# Opción 1: Abrir directamente
xdg-open index.html

# Opción 2: Servidor local
python3 -m http.server 8080
# Abrir http://localhost:8080
```

## Estructura

```
├── index.html    → Estructura semántica de la página
├── style.css     → Estilos y diseño responsive
└── script.js     → Interacciones (menú, scroll, animaciones)
```
